# LRC Recording

A library for reading and writing LRC recordings used by the LabIR® thermographic software. The library can read and write temperature data, thermographic parameters, metadata about measurement, and supplemental data from additional measuring devices. It is available as both statically and dynamically linked. There are also scripts for use with Python and MATLAB. You can find more information about the LabIR system at https://software.labir.eu

## LRC file format

LRC is an open format for storing and sharing thermographic data measured by infrared thermal cameras. The format is independent of camera manufacturer. It is also used by the LabIR EDU education platform https://edu.labir.eu The format specification can be found in docs/LRC-FORMAT.md
